## Règles de preuve

Chaque chiffre porte une note de qualité. Sans note, le chiffre n'entre pas.

- **A** : source primaire, sans intérêt commercial dans le résultat, méthode
  publiée. Papiers académiques, statistiques officielles, textes réglementaires,
  rapports d'institutions dont le métier n'est pas de vendre la chose mesurée.
- **B** : source primaire avec intérêt commercial. Éditeurs, cabinets d'analyse,
  fournisseurs de modèles. Le chiffre est réel, la question posée est orientée.
- **C** : chiffre repris de seconde main, méthode non consultable. Utilisable
  comme indice, jamais comme preuve, jamais dans un document client.

Trois interdits :
1. Un chiffre sans son année, sa taille d'échantillon et son commanditaire n'est
   pas un chiffre.
2. Deux sources qui se contredisent restent toutes les deux dans le document,
   avec l'explication de l'écart. On ne garde pas celle qui arrange.
3. Ce qui contredit la thèse SauronID est écrit en premier, pas en note de bas
   de page.

## Péremption

Un document de recherche porte sa date. Passé six mois sans revue, il est marqué
périmé en tête de fichier ou supprimé. Un chiffre de 2024 sur l'adoption de l'IA
ne décrit plus rien en 2026.

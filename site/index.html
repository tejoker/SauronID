Run it

1 · Start the gateway

Pull the signed image and run it. Verify what you pulled before you run it — the digest is signed by the release workflow.

docker run -p 3001:3001 \
  ghcr.io/tejoker/sauronid/core:VERSION

2 · Point your agent at it

One MCP server covers Claude, Codex, Gemini, Cursor and anything else that speaks MCP. Same three lines in each client's config.

{"mcpServers":{"sauronid":{
  "command":"npx",
  "args":["-y","@sauronid/mcp-server"],
  "env":{"SAURONID_URL":"http://localhost:3001"}}}}

Or use an SDK

Same signed-call flow in three languages, plus adapters for LangChain, LlamaIndex, CrewAI, AutoGen, OpenAI and Anthropic tool use.

pip install sauronid-client
npm i @sauronid/agentic

Verify the image before running it, and reproduce the zero-knowledge guest IDs from published source: verification guide.

Contain the blast radius, prove the history

Signed, not trusted

Each call carries an Ed25519 signature binding method, path, body, nonce, and the agent's exact runtime configuration. Replay, tamper, and prompt-swap all fail closed.

Policy at the gateway

Spend caps, egress rules, and disclosure contracts are evaluated server-side, outside the agent process. A compromised agent cannot argue its way past them.

Receipts you can verify

Actions land in a hash-chained log, batches are externally anchored, and transparent STARK proofs certify compliance statements without trusting the operator.
